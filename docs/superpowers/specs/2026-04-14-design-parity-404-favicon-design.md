# Дизайн-паритет, 404 и favicon

Дата: 2026-04-14
Ветка: `feat/instructions-api-integration`

## Цель

Привести визуальные компоненты проекта инструкций (`NavBar`, `Header`, `Footer`, `BottomNav`) к 1:1 соответствию с основным фронтендом https://learn.open-academy.app, починить темизацию логотипа, завезти полный набор favicon-иконок и реализовать 404-страницу в стиле главного проекта.

## Контекст

Проект встраивается в основной фронтенд. После нормализации URL (спека №1) осталось выровнять визуальную часть: пользователь не должен заметить переход между корневыми разделами (главный) и `/guides/*` (этот проект).

Аудит `academy-frontend` показал:
- Стек — CSS Modules + vanilla CSS + CSS-переменные (совпадает с нашим).
- Шрифт — TT Commons (Regular/Medium/DemiBold) через `@font-face` из `public/fonts`.
- Цвета и токены `src/styles/colors.css` — **значения идентичны** нашим.
- Типографические токены `src/styles/typography.css` — **идентичны**.
- `@font-face` Regular — у них `font-weight: normal`, у нас `400` (эквивалентно, косметика).
- Иконки главного: `iconoir-react` + кастомные SVG. У нас `react-icons/lu` — **оставляем** по решению пользователя.
- Соцсети-иконки: `react-icons/fa`, `react-icons/fa6` — **оставляем**.

## Принятые решения

1. Иконки — остаёмся на `react-icons` (не переводим на iconoir-react и кастомные SVG).
2. Спека одной сплошной, с секциями по зонам.
3. Особое внимание шрифтам: проверить, что `TT Commons` применяется везде и не конфликтует с `Inter`, который сейчас подключён в `layout.tsx` через `next/font/google`.

## Изменения

### 1. Шрифты: убрать Inter, оставить только TT Commons

В `app/[locale]/layout.tsx` сейчас:

```ts
import { Inter } from 'next/font/google';
const inter = Inter({ subsets: ['latin', 'cyrillic'] });
// <body className={inter.className}>
```

Проблема: `inter.className` переопределяет `font-family`, а TT Commons объявлен в `globals.css` на `html { font-family: var(--font-tt-commons); }`. Класс от `next/font/google` применяется к `<body>` и перебивает глобал.

Правки:
- Удалить импорт `Inter` из `next/font/google` и переменную `inter`.
- Убрать `className={inter.className}` у `<body>`.
- Проверить, что `html { font-family: var(--font-tt-commons); }` в `globals.css` задаёт корректный fallback: текущая переменная не определена явно, надо добавить её либо жёстко прописать `'TT Commons', sans-serif`.
- В `src/styles/typography.css` проверить наличие `--font-tt-commons: 'TT Commons', sans-serif;` (если нет — добавить в `:root`).
- Косметика: `@font-face` Regular — поменять `400` на `normal` для соответствия главному (необязательно, но в духе паритета).

### 2. Логотип с темизацией (inline SVG)

Проблема: `<Image src="/brand/academy-logo-full.svg" />` из `next/image` рендерит SVG как растровый `<img>`. `currentColor` в `<img>` не работает → логотип не перекрашивается при смене темы.

Решение — встроить SVG как React-компонент:

- Создать `src/shared/ui/logo/AcademyLogoFull.tsx` — функциональный компонент, возвращающий JSX `<svg>…</svg>` с теми же path'ами, что в `public/brand/academy-logo-full.svg`. Буква «A» сохраняет `fill="#924CFE"`, остальные path'ы — `fill="currentColor"`.
- API: `{ className?: string }`. Размер — через CSS (текущий `.logoIcon { width: 130px; height: auto; color: var(--text-primary); }`).
- Создать `src/shared/ui/logo/index.ts` с реэкспортом.
- В `src/widgets/nav-bar/ui/NavBar.tsx` и `src/widgets/footer/ui/Footer.tsx` заменить `<Image src="/brand/academy-logo-full.svg" … className={styles.logoIcon} />` на `<AcademyLogoFull className={styles.logoIcon} />`.
- CSS `.logoIcon` в NavBar и Footer — оставить `color: var(--text-primary)`, добавить `transition: color 200ms`.
